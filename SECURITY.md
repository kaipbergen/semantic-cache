# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please open a private
[GitHub security advisory](https://github.com/kaipbergen/semantic-cache/security/advisories/new)
instead of a public issue.

Include:
- A description of the vulnerability and its impact
- Steps to reproduce
- Any relevant logs or proof-of-concept code

We'll acknowledge reports as soon as possible and work on a fix.

## Supported Versions

This project is under active development on `main`. Only the latest commit on `main` is supported.
